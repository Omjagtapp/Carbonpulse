System Design

End-to-End Workflow

Each step is seamless — from a single user action to a fully rendered, insight-rich dashboard. No server, no database, no page reload.

01

Input Data

Type kWh, therms, gallons — or drag a CSV file. CarbonPulse validates every row for completeness and correct units before any math runs.

02

Apply Filters & Multipliers

Switching facility (Plant A/B/C) or scenario (Optimized = ×0.85, High Production = ×1.2) multiplies all base inputs and recalculates instantly via React state.

03

Calculate CO₂e

Each adjusted input × its EPA emission factor → kg CO₂e. Results split into Scope 1 (combustion) and Scope 2 (electricity). All math runs in the browser.

04

Visualize & Analyze

Recharts renders the 6-month area trend, donut scope split, and horizontal bar source breakdown. The insights engine generates 5 plain-English recommendations from live values.

05

Plan & Simulate

The Scenario Planner lets users drag sliders to model future changes — electricity reduction, gas cut, renewable switch — before committing any resources.

06

Export & Report

jsPDF generates a formatted multi-table report. GHG Protocol CSV is pre-filled for regulatory submission. A clipboard copy pastes a plain-text summary anywhere. All in under 1 second.

Styling

3 Key Design Decisions

1

Single useState → all calculations

No useEffect for math. All 20+ values recompute fresh on every render — no stale state bugs possible.

2

Zero backend — 100% browser

Validation, charts, PDF export, and CSV parsing all run client-side. Deploy as a static file anywhere.

3

Modular file structure

8 components + 2 utility files. Each concern is isolated — swap a calculation or chart without touching the UI.
